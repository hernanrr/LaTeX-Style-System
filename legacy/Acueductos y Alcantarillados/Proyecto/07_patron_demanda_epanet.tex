\section{Uso del patr\'on}
El patr\'on siguiente se entrega como referencia para la simulaci\'on horaria de la red de agua potable. Los valores representan multiplicadores horarios normalizados y deben aplicarse de forma consistente con la demanda base adoptada en el modelo.

\section{Nota de uso}
\begin{itemize}
\item El equipo debe explicar en la memoria c\'omo defini\'o la demanda base sobre la cual aplica el patr\'on.
\item Si se decide ajustar el patr\'on, debe justificarse el cambio.
\item Este anexo sirve como insumo de modelaci\'on; no sustituye la justificaci\'on de caudales de dise\~no.
\end{itemize}
